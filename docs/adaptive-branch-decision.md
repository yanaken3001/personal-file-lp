# アダプティブ分岐（PRECISION CHECK）の設計判断記録（2026-06）

## 経緯
旧「レア分岐（10人に1人）」はほぼ全ユーザーに発動しており、虚偽の希少性表示と
なっていたため、コピーのみ「精密判定訴求」に変更した（PR #6）。

## 調査事実（10,000件モンテカルロ・詳細は当時のセッション調査）
- 発動条件：57問完了時、基本タイプ軸の上位2軸差<=2で+4問、行動類型軸差<=1で+4問（最大8問）
- 一貫回答（p=0.8）なら発動率10%だが、実ユーザーに近い中央寄り回答（「3」60%）では91.7%
- 原因はバグではなく、リッカート中央化傾向によるスコア差の圧縮
- 閾値を完全同点まで絞っても発動20〜28%。整数閾値で10%は到達不可能
- 追加8問の精度貢献は実在：発動ケースの49〜89%で最終タイプが変化

## 結論（変更してはいけないこと）
- 発動条件・閾値・診断ロジックは意図的に「不変」と判断済み。
  閾値を絞る変更は境界層の診断精度を犠牲にするため、安易に行わないこと
- 文言を「レア・希少」系の訴求に戻さないこと（実態と乖離するため）
- 再検討の条件：分岐画面の実離脱率が深刻と判明した場合のみ
- 中期課題：5件法→4件法（中央選択肢廃止）。実施はPF本体の診断エンジン
  妥当性検証とセットでのみ可

## 追記（2026-10-08）レア度の段階表示を再導入

2026-10-08 ユーザー判断で、実データ（16タイプ別の出やすさ）に基づく段階表示としてレア度を再導入。旧「レア分岐（10人に1人）」の虚偽表示とは別物で、人数・割合は表示しない。

- 単位は16タイプ（personality_type）。80CODE単位にはしない。
- 段階（GA4実績 2026-07-16〜2026-10-07・251人から決定）: ★1「スタンダード」= IP・AD・IA・PD・AI・DP・PI・PA ／ ★2「ちょっと珍しい」= DA・ID・AP ／ ★3「レア」= II・DI ／ ★4「超レア」= PP・AA・DD。
- 上の「変更してはいけないこと」との関係: 発動条件・閾値・診断ロジックは変えていない。「文言をレア・希少系の訴求に戻さない」は、追加8問の発動（分岐）をレアと見せる訴求を指す。今回の段階表示は分岐や追加質問と無関係で、結果のタイプについての「出やすさの目安」。人数・割合・「○人に1人」「まだ誰も出ていない」などの件数表現は画面・画像・計測値のどこにも出さない。
- 結果画面に根拠の注記を小さく添える（画像には入れない）。見直しの目安は診断完了者500人超。段階表は `80cards/src/app.jsx` の `RARITY_TIER_BY_TYPE`。
